# من المحتال؟ 🎭

لعبة استنتاج جماعية تعمل على جهاز واحد (Pass & Play) — كل اللاعبين يمرّرون الهاتف بينهم، وواحد فقط بينهم **محتال** لا يعرف الكلمة السرّية.

> **لا خادم، لا حسابات، لا إنترنت.** اللعبة كلها في ملف HTML واحد، وبيانات الكلمات مضمّنة داخله.

## كيف تلعبون

0. **اللعبة جاهزة فوراً:** تفتح وفيها **4 لاعبين افتراضيون** (لاعب 1 … لاعب 4) وكل التصنيفات مختارة — اضغط «ابدأ اللعبة» في الشريط السفلي مباشرة. عدّل الأسماء بالضغط على **القلم ✎** بجانب أي اسم.
1. **أضيفوا اللاعبين** (3 على الأقل، حتى 20) واختاروا التصنيفات التي تحبونها.
2. مرّروا الجهاز بين اللاعبين. كل لاعب **يضغط مطوّلاً** على الكرت ليرى دوره، ويُفلت فيُغلق الكرت فوراً.
3. **المدنيون** يرون الكلمة السرّية نفسها، و**المحتال** يرى «أنت المحتال!» فقط.
4. في **وقت النقاش** كل لاعب يقول جملة واحدة تصف الكلمة دون ذكرها — والمحتال يتظاهر بأنه يعرفها.
5. ناقشوا بحرية (لا مؤقّت)، وعندما تنتهون اضغطوا **«إنهاء اللعبة»** ليُكشف المحتال والكلمة السرّية أمام الجميع.

### الواجهة
- **شريط سفلي ثابت (Bottom Bar)** يحمل الزر الأساسي لكل شاشة: *ابدأ اللعبة* ← *اللاعب التالي* ← *الانتقال إلى التصويت* ← *كشف النتيجة* ← *جولة جديدة*، فما عليك تمرير الصفحة للعثور على الزر.
- **تعديل الأسماء في مكانها:** اضغط القلم على أي وسم لاعب، اكتب الاسم، ثم Enter للحفظ أو Esc للإلغاء.

### الأنماط والإعدادات
- **عدد المحتالين:** من 1 إلى 3 (مع بقاء مدني واحد على الأقل).
- **وضع الفوضى:** نسبة من 10% إلى 50% أن يصبح **كل اللاعبين محتالين** في الجولة — ولا أحد يعلم، ولا حتى المحتال نفسه.
### نهاية الجولة
لا يوجد تصويت ولا مؤقّت. بعد كشف هوية الجميع يبدأ **النقاش المفتوح**، وعندما تنتهون اضغطوا **«إنهاء اللعبة»** في الشريط السفلي — فتُكشف الكلمة السرّية وأسماء المحتالين أمام الجميع.

## الجانب التقني

- **ملف واحد:** HTML + CSS + JavaScript خام، بدون أي مكتبة إلزامية.
  Tailwind CSS و خطوط *IBM Plex Sans Arabic* مُحمّلان عبر CDN كطبقة تجميلية، **لكن كل التنسيقات الحرجة مكتوبة CSS خام** — اللعبة تعمل وتظهر بنفس الشكل تماماً بدون إنترنت.
- **RTL كامل** وبخط عربي من البداية.
- **أيقونات SVG** مرسومة داخل الملف (بدون مكتبات أو إيموجي).
- **أيقونة التطبيق وبيان PWA** مضمّنان كـ `data URI` داخل `index.html`، لذلك التثبيت على الشاشة الرئيسية يعمل حتى أوفلاين.
- **التصميم:** نمط **«حفلة ملوّنة»** — خلفية كريمية منقّطة، حدود سميكة وظلال صلبة (بلا توهّج)، ألوان كورال/أصفر/مريمي، خطوط *Baloo Bhaijaan 2* للعناوين و*Tajawal* للمتن. لا مؤثرات صوتية إطلاقاً.
- **اللمس:** الضغط المطوّل يعمل بـ `touchstart/touchend` و `mousedown/mouseup` ولوحة المفاتيح، مع تفادي مشكلة إنهاء الضغط بسبب إعادة التخطيط في المتصفحات المحمولة.
